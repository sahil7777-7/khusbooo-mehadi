# Khushbu Yadav — Professional Mehndi Artist Portfolio

A luxury, high-end, responsive portfolio website for **Khushbu Yadav**, Professional Mehndi Artist.

## Features
- **Authentic Artwork Gallery**: Displays all 12 uploaded Mehndi photos in a modern asymmetric masonry layout with subtle hover depth, henna-inspired gold glow, and full-screen lightbox navigation (image counters, previous/next buttons, touch swipe, keyboard arrows, escape to close).
- **Brand Identity**: Elegant, feminine branding featuring Khushbu Yadav throughout the site.
- **Dedicated Instagram Section**: Seamlessly integrated showcase featuring handle `@shivkhushbooyadav22` and a stylish "Follow Khushbu Yadav on Instagram" CTA button linking to Khushbu's profile.
- **Direct Contact & Bookings**: Direct mailto integration and booking form pointed to `shivkushbooyadav@gmail.com`.
- **Performance & Smooth Motion**: Hardware-accelerated transitions, subtle parallax, custom cursor, and responsive layout across mobile, tablet, and desktop devices.

## Running the Website
No build tools or installation required. Open `index.html` directly in any web browser or host on any static hosting platform (GitHub Pages, Vercel, Netlify, etc.).
